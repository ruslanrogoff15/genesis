# Склад — ТЗ на ЛВС и Wi‑Fi

Техническое задание на проектирование и построение ЛВС и беспроводной сети Wi‑Fi нового складского корпуса, примыкающего к основному складу (Минский р‑н, район д. Таборы).

Главные требования к проекту:

- активное оборудование — только **Huawei**; Wi‑Fi управляется существующим контроллером на коммутаторе ядра основного склада;
- перед проектированием подрядчик обязан провести **радиообследование** (предпроектное и приёмочное);
- основные клиенты Wi‑Fi — **ТСД** (терминалы сбора данных), в том числе устаревшие Wi‑Fi 4 только на 2,4 ГГц;
- видеонаблюдение и СКУД в объём работ не входят.
